Ограничения 
Запрещено: 
• шаблоны (template); 
• контейнеры STL (std::vector, std::map, std::set, std::list, …); 
• умные указатели (std::unique_ptr, std::shared_ptr, std::weak_ptr); 
• std::array, std::span, std::optional.

Обязательные требования: 
1. Деструктор освобождает data_ через delete[]. 
2. Копирующий конструктор выделяет новый массив и копирует элементы 
(глубокая копия, а не копирование указателя). 
3. Копирующее присваивание реализуется через copy-and-swap: сильная 
гарантия исключений, корректная работа с самоприсваиванием. 
4. Перемещающий конструктор забирает data_, обнуляет источник и 
помечен noexcept. 
5. Перемещающее присваивание освобождает свой ресурс, забирает чужой, 
корректно обрабатывает самоперемещение и помечено noexcept. 
6. Рост capacity — по стратегии варианта: –  – удвоение
7. Удаление — по стратегии варианта: сдвиг с сохранением порядка или swap
with-last без сохранения порядка.

Операции над множествами 
Семантика операций: 
• A | B — все элементы, которые есть в A или в B; 
• A & B — элементы, которые есть и в A, и в B; 
• A - B — элементы A, которых нет в B; 
• A ^ B — элементы, которые есть ровно в одном из множеств 
(симметрическая разность; в вариантах, где она требуется); 
• A <= B — A является подмножеством B.
