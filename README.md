## Что было необходимо сделать.

1. Реализовать класс с ручным управлением динамической памятью.

4. Применить идиому copy-and-swap для безопасного присваивания.
5. Написать модульные тесты для всех операций

Класс для реализации:
String: строковый класс с динамическим массивом char*

Запрещено использовать std::string, std::vector, std::array, умные указатели —
только ручное управление памятью (new[] / delete[]).
RAII
• Конструктор выделяет память, деструктор освобождает.
• Никаких утечек памяти при любом сценарии использования.
Правило пяти
• Конструктор копирования: глубокое копирование буфера.
• Конструктор перемещения: «обнуляет» источник (O(1)).
• Присваивание: используйте идиому copy-and-swap.
• Деструктор: delete[] буфера.
Copy-and-swap
// Оператор присваивания принимает аргумент ПО ЗНАЧЕНИЮ.
// Компилятор сам вызовет конструктор копирования или перемещения.
T& T::operator=(T other) {
swap(other);
return *this;
}
Память
• Все промежуточные выделения памяти должны быть освобождены.
Тесты
• Не менее 12 тестов Google Test: на базовое поведение класса и на алгоритм
варианта.
• Тестируйте граничные случаи: пустой объект, один элемент,
самоприсваивание, копирование/перемещение, конкатенация с пустым
объектом.

Строковый класс без использования std::string. Для хранения символов —
динамический массив char*.
Стратегия роста буфера
• При push_back / append: если size_ == capacity_, увеличивайте capacity_ в 2
раза.
• Минимальная начальная ёмкость: 1.
• Всегда выделяйте capacity_ + 1 байт для завершающего '\0'.
Примеры использования
#include "string.h"
#include <iostream>
int main() {
String s1; // ""
String s2("Hello"); // "Hello"
String s3(s2); // "Hello" (копия)
String s4(std::move(s3)); // "Hello" (перемещение, s3 теперь пуст)
s1 = s2; // копирующее присваивание
s1.append(", World!");
s1.print(std::cout); // "Hello, World!"
size_t pos = s1.find("World");
std::cout << pos << std::endl; // 7
return 0;
}
